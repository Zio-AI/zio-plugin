ZIO 플러그인은 Claude Code·Codex 및 두 앱의 코드 화면에서 ZIO 연결과 새 자료 건수 알림을 제공합니다.
목록 추가: Claude Code 터미널에서 `claude plugin marketplace add https://github.com/Zio-AI/zio-plugin.git` (Codex: `/plugins` → Add Marketplace → 같은 주소).
설치: `claude plugin install zio@zio-ai --scope user` (Codex: 목록에서 Zio 선택 → 설치).
Codex CLI 0.164.0에서는 설치 또는 갱신 후 터미널에서 `codex features enable mcp_2026_07_28`을 한 번 실행하고 Codex를 다시 시작하세요. ZIO 플러그인은 MCP 2026-07-28 규격을 사용하며, 0.1.4부터 Codex용 연결 설정에도 이 판을 명시합니다.
Windows용이며 Codex 알림은 PowerShell에서 지원합니다.
